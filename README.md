# Обществознание · ОГЭ-2027 · тренажёр

Статический сайт (HTML/CSS/JS без сборки) для подготовки к ОГЭ-2027 по обществознанию: банк заданий по номерам 1–20, полные варианты с таймером, автопроверка, библиотека коротких конспектов и статистика. Прогресс хранится в браузере (localStorage).

Формат — строго по демоверсии, спецификации и кодификатору ФИПИ 2027. Определения — по учебнику «Обществознание. 9 класс» под ред. Д. А. Медведева. Свои задания и тексты помечены «составлено для тренажёра».

## Как устроено
- `index.html` — оболочка; `js/app.js` — интерфейс (маршруты `#/…`); `js/check.js` — проверка по правилам ФИПИ.
- `data/meta.js` — формат экзамена (`OGE.NUMBERS`), разделы и кодификатор.
- `data/library.js` — конспекты `OGE.LIBRARY[1..20]` и словарь `OGE.GLOSSARY`.
- `data/tasks/nNN.js` — задания одного номера: `OGE.addTasks([...])`; тексты для 18–20 — `OGE.addText(id, {...})`.
- `data/variants.js` — фиксированные варианты.

## Схема задания
Общие поля: `id`, `n` (номер 1–20), `code` (кодификатор), `level`, `facts` (чтобы в варианте не было двух заданий на один факт), `text`, `explain`, `lib` (`"N#раздел"` — ссылка на конспект), `source`, `added`.

- Краткий ответ: `options`, `key` (цифра / строка цифр / `{sim:[], diff:[]}` для №3 / слово для №2), `why` — пояснение к каждому варианту.
- Развёрнутый ответ: `fields` (поля ввода), `elements` (смысловые элементы: `keys` — группы основ слов, `minWords`, `deny`, `atLeast`), `rubric` (`t1`, `gate`, `count`, `t12b`, `plan`, `t20`), `reference` (эталон), `criteria`.

## Проверка развёрнутых ответов
Система ищет смысловые элементы по ключевым словам и считает балл по критериям ФИПИ. Это ориентир: после проверки показывается эталон, и ученица может поправить отметки элементов.
