# «Маркер» · домашняя работа по обществознанию

Первый рабочий сценарий кабинета Миши. Репетитор добавляет ученика, выбирает до 20 заданий, указывает срок и записку, копирует ссылку на работу. Ученик переходит в «Сегодня», решает по одному заданию, видит список перед сдачей и получает разбор. После сдачи оригиналы ответов, баллы и ошибки доступны репетитору.

## Попробовать локально

Требуется Node.js 24 или новее. Из корня репозитория:

```bash
cd marker
npm ci
npm run demo
```

Открой адрес, который напечатает сервер, и введи показанный там код репетитора. Есть два вымышленных ученика и образец работы из банка ОГЭ. Для проверки второй сессии вставь ссылку на работу в другом браузере или в приватном окне. У каждого запуска демо своя временная база.

## Запуск с постоянной базой

```bash
npm ci
node -p 'require("node:crypto").randomBytes(24).toString("base64url")'
MARKER_TUTOR_CODE='<сгенерированный код>' npm start
```

Для постоянной установки сохрани один сгенерированный код в конфигурации процесса и сообщи его репетитору. Используй `MARKER_DB` для пути к SQLite в постоянном каталоге. По умолчанию база лежит в `marker/data/homework.sqlite`. Сервер слушает `127.0.0.1:4317`. Параметры `MARKER_HOST` и `PORT` задают другой адрес прослушивания. При запуске за HTTPS-прокси задай `MARKER_URL` равным внешнему адресу приложения, чтобы ссылки вели на него, а куки передавались через HTTPS. Личные ссылки дают доступ к работам ученика, поэтому их следует отправлять лично и исключить полные пути `/s/…` из журналов доступа прокси.

Если ссылку переслали, открой страницу ученика и выбери «Заменить личную ссылку». Старые ссылки и сессии этого ученика перестанут работать. Работы и ответы сохранятся. Новые ссылки на конкретные работы можно скопировать из кабинета.

Для резервной копии работающей базы используй команду SQLite `.backup`, например `sqlite3 /path/to/homework.sqlite ".backup '/path/to/backup.sqlite'"`. Чтобы восстановиться, останови приложение и запусти его с `MARKER_DB`, указывающим на восстановленную копию в постоянном каталоге.

Черновики сохраняются в SQLite по мере ввода и при переходе между заданиями. Состояние задания хранится с версией, поэтому изменения из другого окна требуют сверки. Сдача фиксирует баллы и ответы в одной транзакции. Бумажные и развёрнутые ответы, экзамен с таймером, конспекты и тетради истории относятся к следующим этапам.

## Источник заданий

«Маркер» читает тот же банк `../data/tasks/` и использует проверку из `../js/check.js`. Изменения в банке подхватываются при следующем запуске. В этом сценарии используется 97 заданий с кратким ответом, включая выбор ответа, слово, сравнение и соответствие. Банк и ключи используются на сервере. При назначении работы условие и ключ фиксируются в базе вместе с работой. Интерфейс использует локальные файлы шрифтов Sofia Sans, Sofia Sans Extra Condensed и Caveat.

## Проверка

После `npm ci` запусти `npm test` в каталоге `marker/`. Тест поднимает отдельный сервер с временной базой и проверяет назначение, продолжение работы по ссылке, сдачу, частичный балл за соответствие, перевыпуск ссылки и сохранение результата после перезапуска.
